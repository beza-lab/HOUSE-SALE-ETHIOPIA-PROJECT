House Sale Ethiopia
A Flask-based real estate web application where users can register, log in, post houses for sale or rent, upload property images, search listings, and manage their own properties.

Features
- Public Users
View latest property listings
Search houses by city or property title
View property details
Browse all available listings

- Registered Users
Create an account
Log in and log out
Add new house listings
Upload property images
Edit their own listings
Delete their own listings

- Admin Users
Log in as administrator
View all listings
Edit any listing
Delete any listing
Manage the platform

- Technologies Used
Python 3
Flask
Flask-Login
SQLAlchemy
SQLite
Bootstrap 5
HTML5
CSS3
Jinja2
